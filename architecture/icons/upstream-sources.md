# Official logo sources

The files in this directory are downloaded copies of the upstream artwork. They are kept as original SVG/PNG assets; no paths or shapes were redrawn.

| Asset | Upstream source | Notes |
| --- | --- | --- |
| `nextjs.png` | [Vercel Next.js brand asset](https://assets.vercel.com/image/upload/v1662130559/nextjs/Icon_dark_background.png) | Official Next.js icon asset served by Vercel. |
| `nestjs.svg` | [Nest official website logo](https://nestjs.com/img/logo-small.svg) | Referenced by the official [`nestjs/nest` README](https://github.com/nestjs/nest). |
| `kubernetes.svg` | [CNCF artwork repository](https://github.com/cncf/artwork/blob/main/projects/kubernetes/icon/color/kubernetes-icon-color.svg) | Official CNCF Kubernetes color icon. |
| `kyverno.svg` | [CNCF artwork repository](https://github.com/cncf/artwork/blob/main/projects/kyverno/icon/color/kyverno-icon-color.svg) | Official CNCF Kyverno color icon. |
| `postgresql.svg` | [PostgreSQL official wiki logo](https://wiki.postgresql.org/wiki/File:PostgreSQL_logo.3colors.svg) | Official three-color PostgreSQL/Slonik logo; use is subject to the PostgreSQL trademark policy. |

The architecture diagram uses these assets only as visual references for the named technologies. Review the upstream project trademark and artwork guidance before redistributing the final submission outside the graduation project.
